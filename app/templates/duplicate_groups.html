What is a Duplicate Group?

A duplicate group represents multiple file references that share the exact same SHA-256 content hash. CloudDedup stores only one physical object in Firebase Cloud Storage, preserving 100% of the redundant space. Only groups with 2 or more of your active references are shown here.
